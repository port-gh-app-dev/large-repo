# AI Coding Rules

This repository is the source of truth for AI coding guidance used by agents and assistants.

## Objectives
- Enforce secure-by-default implementation patterns.
- Standardize coding and documentation behavior across projects.
- Provide reusable, practical rules for daily engineering workflows.

## Rule Locations
- `.cursor/rules/security/` contains security-focused implementation rules.
- `.github/instructions/` contains cross-cutting coding and documentation instructions.

## Usage Principles
- Apply these rules by default in all generated or reviewed changes.
- Prefer minimal, testable, backward-compatible updates.
- Escalate when requirements conflict with security or compliance constraints.
